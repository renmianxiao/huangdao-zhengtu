# 黄道征途

一款可以离线游玩的武侠回合制策略游戏。招募侠客，调整阵位，在五层征途中选择路线、收集藏品并挑战守关对手。

## 下载游戏

在 [GitHub Releases](https://github.com/renmianxiao/huangdao-zhengtu/releases/latest) 的 **Assets** 下选择安装包。

| 平台 | 安装包 | 运行要求 |
| --- | --- | --- |
| Windows | `Huangdao-Zhengtu-Windows-v0.2.2.exe` | Windows 10 或 11，64 位，支持 OpenGL 3.3 |
| Android | `Huangdao-Zhengtu-Android-v0.3.0.apk` | Android 7.0 及以上，支持 OpenGL ES 3.0，ARM64 设备或 x86_64 模拟器 |

## 从源码运行桌面版

使用 Godot 4.7.2 标准版导入根目录的 `project.godot`。首次打开时等待资源导入完成，按 **F6** 可运行当前场景，按 **F5** 启动完整游戏。游戏逻辑和场景位于 `code/`，美术资源位于 `art/`，音乐和音效位于 `audio/`。

Windows 安装、操作与存档位置见[游戏说明](./游戏说明.txt)。字体许可随文件保存在 `art/fonts/`，过场声音的来源和署名见[过场素材记录](./art/cinematics/ink/credits.json)。
